# Daily-Spending-Tracker-Offline
Daily Spending is an iOS app that turns bank messages into a spending dashboard: ✅ Reads the SMS, then picks out the amount, debit or credit, merchant, date and account ✅ Auto-categorises: food, groceries, travel, bills ✅ Monthly summary, 7-day chart and category breakdown ✅ Data stays on the phone. No server, no bank login, no API
